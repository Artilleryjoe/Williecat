🐾 Williecat v0.1 – Reconnaissance with Instinct

The first public build of Williecat, a passive reconnaissance and OSINT assistant built in memory of Willie.

**Features:** Quiet mode, demo mode, structured logging, and Markdown/JSON reporting.
